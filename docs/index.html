03

내 컴퓨터 분석하기

시작 화면의 버튼을 누르면 측정을 시작하고, 프로그램별 사용량과 추이를 보여줍니다.

이 웹사이트는 제품 소개와 다운로드 안내 페이지입니다. 브라우저에서 이 페이지만 열어서는 PC 자원을 측정하지 않습니다.

연동 앱을 위한 안정 분배

중앙 스위치 하나로 제어합니다. GPU 사용률 60% 이상을 관측하면 CPU 지원 검사는 이후 60초 동안 CPU를 우선 선택하고, CPU 검사를 정상 완료할 때마다 이 기간을 60초 연장합니다. GPU 전용 작업은 문장 경계에서 기다리며, GPU 사용률 40% 이하가 5초 유지되면 재개를 허용합니다. CPU·메모리 여유와 측정 상태도 확인합니다. 개발자가 SDK를 연동한 작업에 적용하며, 모든 외부 프로그램을 강제로 전환하거나 GPU 사용률을 60%로 고정하지 않습니다.

짧은 변화부터 긴 흐름까지

약 1초 단위의 실시간 흐름과 15초 단위 요약 기록을 구분해 봅니다. 최근 7일 기록은 CSV로 내보낼 수 있습니다.

기록은 내 컴퓨터에

분석 기록은 실행 중인 PC에 저장됩니다. 프로그램이 측정한 자원 사용량을 외부 분석 서버에 전송하지 않습니다.

구매 판단을 위한 근거

높은 부하가 반복되는 시간과 프로그램을 확인합니다. 순간 GPU 사용률만으로 부품 교체를 권하지 않습니다.

지원 환경
Windows 10 / 11 x64용입니다. macOS·Linux·휴대폰용 측정 프로그램은 제공하지 않습니다.
