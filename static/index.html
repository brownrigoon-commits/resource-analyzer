프로그램을 선택하면 개별 프로세스 사용량을 볼 수 있습니다.

측정 기준 CPU는 전체 논리 프로세서 기준으로 정규화합니다. 프로그램 메모리는 작업 집합의 합계로 공유 메모리가 중복될 수 있습니다.

전체 GPU 카드는 NVIDIA 장치, 프로그램 GPU는 Windows가 보고하는 엔진 기준입니다. 대상 장치·엔진 집계·표본 시점 차이로 프로그램 합계와 전체 값이 다를 수 있습니다.

프로그램 I/O는 파일·장치의 논리 I/O로, 위의 물리 디스크 전송량과 다릅니다. — 는 미측정입니다.
