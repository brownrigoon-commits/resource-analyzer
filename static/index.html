    연동 작업의 CPU 지원

    • 지원 정보를 확인하고 있습니다.

    CPU 지원이 확인된 연동 작업에만 다음 작업·문장 경계부터 적용합니다. 실행 중인 계산과 연동하지 않은 외부 앱의 실행 장치는 강제로 바꾸지 않습니다.

    GPU 60%는 다음 작업의 분배 판단 기준입니다. 사용률을 60%로 제한하는 기능이 아니므로 GPU가 순간 100%에 도달할 수 있습니다.

    최근 60초 동안 GPU 부하가 높았다면 다음 CPU 지원 검사도 CPU로 선택합니다. CPU 검사가 정상 완료되면 이 선호 기간을 연장합니다. GPU 전용 작업의 재개 기준은 40% 이하 5초로 유지합니다.

    선택·완료 횟수는 서버에 기록된 실제 결과만 표시합니다. CPU 지원 표시는 실행 경로의 지원 여부이며, 완료 횟수와 별도로 확인합니다.

    측정 대기 중
    프로그램 정보를 불러오는 중입니다.
    프로그램을 선택하면 개별 프로세스 사용량을 볼 수 있습니다.

    측정 기준 CPU는 전체 논리 프로세서 기준으로 정규화합니다. 프로그램 메모리는 작업 집합의 합계로 공유 메모리가 중복될 수 있습니다.

    GPU는 제조사 측정값 또는 Windows의 가장 바쁜 엔진 사용률을 표시합니다. 여러 GPU 중 높은 사용률을 상단에 표시하며, 아래 장치 목록에서 각각 확인할 수 있습니다. 프로그램 합계와 장치 사용률은 집계·표본 시점 차이로 다를 수 있습니다. 공유 메모리 한도는 GPU 전용 메모리가 아닙니다.

    프로그램 I/O는 파일·장치의 논리 I/O로, 위의 물리 디스크 전송량과 다릅니다. — 는 미측정입니다.
